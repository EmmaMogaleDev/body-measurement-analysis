📊 Body Measurement Data Analysis (EDA Project)
🧠 Overview

This project explores human body measurement data using exploratory data analysis (EDA) techniques. The goal is to understand relationships between different physical measurements, identify proportional patterns, and analyze how body structure varies across individuals.

The analysis focuses on correlations, proportions, and distribution patterns rather than predictive modeling.

🎯 Objectives
Analyze relationships between height and other body measurements
Identify strong correlations between body dimensions
Understand skeletal vs soft tissue measurement patterns
Explore proportional relationships across different body groups
Evaluate consistency of human body structure across height categories
📁 Dataset Description
Source: AWS PartyRock “Body Measurement Dataset”
Samples: 2,018 individuals
Features: 14 body measurements
Height
Arm length
Leg length
Torso length
Shoulder width
Chest circumference
Waist circumference
Hip circumference
Bicep, thigh, calf, ankle, wrist measurements
Data Quality: Complete dataset (no missing values)
🔧 Tools Used
AWS PartyRock (data analysis feature)
Correlation analysis
Ratio-based analysis
Grouped statistical summaries
Exploratory data analysis (EDA)
